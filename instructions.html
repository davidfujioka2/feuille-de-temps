Installer « Chantier » sur l’iPad

Journal de chantier et feuille de temps · Beaudoin Capital · adresse : davidfujioka2.github.io/feuille-de-temps

1Vérifier les réglages de l’iPad

  1. Ouvrir Réglages.
  2. Toucher Apps › Safari.
  3. Désactiver Bloquer tous les cookies.
  4. Toucher Général › Stockage de l’iPad : garder au moins 2 Go libres.
  5. Ouvrir le Centre de contrôle (glisser du coin en haut à droite) : désactiver le verrouillage de la rotation.
  6. Se connecter au Wi-Fi.

2Ouvrir le site dans Safari

  1. Ouvrir Safari.

3Ajouter l’app à l’écran d’accueil

  1. Toucher le bouton Partager (carré avec une flèche vers le haut). S’il n’est pas visible : toucher •••, puis Partager.
  2. Toucher Afficher plus.
  3. Toucher Sur l’écran d’accueil.
  4. Vérifier que Ouvrir en tant qu’app web est activé (vert).
  5. Laisser le nom Chantier.
  6. Toucher Ajouter.

4Premier lancement (avec internet)

  1. Retourner à l’écran d’accueil.
  2. Toucher l’icône Chantier.
  3. Attendre que le calendrier s’affiche (l’app se copie sur l’iPad).
  4. Fermer l’app, puis la rouvrir une fois avec l’icône.
  5. À la première photo, toucher Autoriser pour l’appareil photo.

5Vérifier que l’app marche sans internet

  1. Ouvrir le Centre de contrôle, activer le mode Avion.
  2. Toucher l’icône Chantier.
  3. Le calendrier doit s’afficher.
  4. Désactiver le mode Avion.
✈︎
En mode Avion, le calendrier s’ouvre quand même

6Tous les jours

  1. Ouvrir l’app avec l’icône Chantier, jamais dans Safari.
  2. Journal de chantier : choisir la journée dans le calendrier.
  3. Feuille de temps : onglet Feuille de temps en haut du calendrier.
  4. Mises à jour : ouvrir l’app une fois avec internet ; la nouvelle version s’affiche au lancement suivant.
Ne jamais supprimer l’icône Chantier : les données sont gardées dans l’iPad et seraient effacées.

7OneDrive : documents du bureau hors connexion

  1. Ouvrir l’App Store, installer Microsoft OneDrive.
  2. Ouvrir OneDrive, se connecter avec le compte de travail (@coreholdings.ca).
  3. Trouver le dossier du projet.
  4. Toucher ••• à côté du dossier.
  5. Toucher Rendre disponible hors connexion.
  6. Avant d’aller au chantier : ouvrir OneDrive sur le Wi-Fi quelques secondes pour recevoir les derniers fichiers.
  7. Icône nuage = pas téléchargé. Coche = disponible sans internet.
